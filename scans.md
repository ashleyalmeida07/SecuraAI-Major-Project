1. Recon Flow (Surface Mapping)
Crawler Node: Uses Playwright (a headless browser) to navigate the website, click buttons, and extract all URLs, forms, and API endpoints.
Classifier Node: An AI agent looks at the data for each endpoint and tags it (e.g., "Login Page", "Static Asset", "API").
Surface Report Node: Aggregates everything into a clean map of the application's attack surface.
2. Full Scan (Header Audit)
(Starts by running the entire Recon Flow above)
Header Scanner Node: Fetches the HTTP security headers (like CSP, HSTS) for every discovered endpoint.
Severity Scorer Node: An AI agent evaluates the missing headers. It uses the tags from the Classifier Node to score the risk based on context (e.g., missing headers on a login page = high risk; on a public blog = low risk).
Report Builder: Compiles the findings into a final executive summary.
3. Injection Test
(Starts by running the entire Recon Flow)
Payload Generator Node: AI looks at the forms and parameters discovered by the crawler and crafts custom SQLi and XSS payloads.
Injector Node: Fires two requests for each endpoint: a normal "baseline" request, and the "malicious" injected request.
Response Analyzer Node: An AI agent compares the two server responses. If they are meaningfully different in a way that suggests the payload executed, it definitively confirms the vulnerability.
Report Builder: Compiles the confirmed vulnerabilities into a final report.
4. Static Analysis (SAST)
Dispatch Node: Starts the scan by triggering underlying static analysis tools (like CodeQL).
Merge Findings Node: Collects the raw vulnerability alerts generated by the tools.
Retrieve Context Node: Grabs the actual surrounding source code for each flagged vulnerability.
Triage Node: An AI agent reviews the code to determine if the tool made a mistake, aggressively filtering out false positives.
Fix Generator Node: For the genuine vulnerabilities, the AI writes the actual code required to fix the issue.
Report Builder: Creates the final report containing the triaged issues and the recommended code patches.
